Epic: Customer billing portal (target: one quarter)

Customers should be able to see invoices, update payment methods, download receipts,
change plans, and get email notifications for failed payments.

Current story breakdown:
1. Design and build the complete billing database schema (backend team, 3 weeks)
2. Build all REST API endpoints for invoices, payments, plans, receipts (backend team, 4 weeks)
3. Build the React UI for every billing screen (frontend team, 4 weeks)
4. Wire the UI to the API and fix integration problems (both teams, 2 weeks)
5. Email notifications (platform team, 2 weeks)
6. QA and bug fixing (3 weeks)

Nothing is demoable until story 4 completes.
